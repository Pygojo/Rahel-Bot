Overview
This project shows a small chatbot trained on everyday speech. It answers short questions and handles basic tasks.

Features
Responds to common greetings.
Gives short answers to simple questions.
Handles small prompts in clear language.

How to use
Run the script.
Type your message.
The chatbot replies in real time.

Purpose
This project shows the idea behind a basic conversational tool. It helps beginners understand simple logic and response flow.
